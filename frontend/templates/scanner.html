How to Use the AegisAppSec Autonomous DAST Engine

Unlike legacy scanners that generate thousands of blind requests, AegisAppSec executes a systematic 5-stage phased methodology designed to probe deeply without crashing production assets.

01

Asset Verification & Cryptographic Scope Boundary

Before probing commences, domain ownership is verified cryptographically via DNS TXT records, HTTP tokens, or HTML meta tags, enforcing strict legal and infrastructure boundaries.

SECURITY GUARANTEE
Zero Unauthorized Probing

AegisAppSec rejects targets that do not pass 3-way ownership validation. This protects teams from legal liability and prevents abusive scans against shared third-party subnets.

VERIFICATION METHODS
DNS TXT • /.well-known • Meta

Supports automated DNS TXT record matching, token files under /.well-known/aegis-verification.txt, or signed HTML <meta name="aegis-verification"> tags.

02

Deep Surface Crawling & Parameter Harvesting

Autonomous crawlers map complex single-page apps, parse forms, harvest hidden query parameters, and ingest OpenAPI / Swagger schemas to expose every hidden attack surface.

INPUT EXTRACTION
Forms, Query Strings & JSON Schemas

Extracts every potential injection sink: GET query parameters, POST body forms, JSON payloads, request headers, cookies, and route parameters.

AUTHENTICATED CONTEXT
Bearer JWT • Cookies • Basic Auth

Maintains active user sessions behind login walls. Crawls user profiles, administrative dashboards, and checkout funnels with valid authentication tokens.

03

Multi-Vector Asynchronous Payload Fuzzing

High-concurrency asyncio workers execute non-destructive payload trees across all inputs, evaluating timing delays, error leakages, and response reflections concurrently.

CONCURRENCY & THROTTLING
15 Concurrent Async Tasks

Throttles connections to respect server boundaries while completing exhaustive OWASP scans in seconds instead of hours. Automatic backoff prevents DoS on production.

PAYLOAD DIVERSITY
Multi-Dialect SQLi, SSRF, XSS, IDOR

In-memory payload trees test for Boolean logic, time delays (SLEEP), cloud metadata access, unescaped DOM reflections, and parameter tampering.

04

Zero False-Positive Proof-of-Concept (PoC) Verification

AegisAppSec eliminates false alarms by verifying exploitability. Every reported finding includes the exact raw HTTP request and response evidence proving the vulnerability.

AUDIT-READY EVIDENCE
Raw HTTP Proofs • CVSS v3.1

No theoretical conjectures. Each finding produces the exact exploit payload, HTTP headers, response snippet, and calculated CVSS vector string for engineering review.

1-CLICK TICKET EXPORT
Jira • GitHub Markdown

Export ready-to-triage tickets with steps to reproduce, impact analysis, and remediation guidance formatted specifically for software developers.

05

Split Code Remediation & Real-Time Virtual Patching

Developers receive actionable side-by-side code diffs in Python, Go, Node.js, and PHP, alongside instant 1-click regex virtual patch deployment to the live ASGI WAF shield.

CODE REMEDIATION
Side-by-Side Diff Recipes

Clearly shows how to rewrite raw string concatenation into parameterized queries, apply HTML context encoding, and enforce outbound IP whitelist filters.

IMMEDIATE DEFENSE
ASGI WAF Virtual Patch
