Active Defense HTTP Headers

INJECTED BY app.core.security.SecurityHeadersMiddleware
Strict-Transport-Security [ENFORCED]
max-age=31536000; includeSubDomains; preload
Enforces mandatory TLS 1.3 encryption across all current and future subdomains. Immunizes clients against SSL-stripping and man-in-the-middle downgrade attacks.
Content-Security-Policy [STRICT]
default-src 'self'; frame-ancestors 'none'; form-action 'self'
Restricts origin loading for scripts, styles, objects, and websockets. Blocks malicious inline injection payloads and unauthorized data exfiltration channels.
X-Frame-Options [DENY]
DENY
Prohibits external or same-origin frames from embedding the console in an iframe. Completely mitigates UI redressing and Clickjacking (CWE-1021).
X-Content-Type-Options [NOSNIFF]
nosniff
Instructs browsers to strictly honor declared MIME types. Blocks drive-by downloads and attacks attempting to execute images/SVGs as JavaScript.
X-XSS-Protection [ACTIVE]
1; mode=block
Legacy browser audit defense. Automatically halts page rendering if reflected cross-site scripting is detected in user input vectors.
Referrer-Policy [STRICT]
strict-origin-when-cross-origin
Sends full referrer only when navigating within same origin. Protects sensitive URL tokens and scan session identifiers from cross-origin leakage.
Permissions-Policy [SANDBOXED]
camera=(), microphone=(), geolocation=(), payment=()
Disables browser hardware APIs entirely. Shields security operators from unauthorized sensor access or device fingerprinting.
Server Cloaking [MASKED]
Server: Aegis-Gateway/Hardened
Masks Uvicorn and FastAPI signature banners. Prevents adversaries from fingerprinting backend Python microservice runtimes and frameworks.
